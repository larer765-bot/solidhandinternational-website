# SolidHand International — site web

Site vitrine responsive en HTML, CSS et JavaScript, rédigé en français.

## Aperçu local

Ouvrir `index.html` dans un navigateur. Aucun outil de compilation n’est nécessaire.

## Avant publication

Les coordonnées, chiffres d’impact, projets, témoignages, photos, partenaires et informations légales doivent être fournis et validés par SolidHand International. Le contenu actuel évite d’inventer ces informations.

Pour activer le formulaire de contact, renseigner l’adresse officielle dans `CONTACT_EMAIL` au début de `script.js`. Le formulaire ouvre alors le logiciel de messagerie du visiteur (il ne transmet pas les données à un serveur).

Le site charge les polices DM Sans et Manrope depuis Google Fonts ; des polices de secours sont prévues si le service n’est pas disponible.

## Publication

Le site peut être publié avec GitHub Pages depuis les paramètres du dépôt, en choisissant la branche `main` et le dossier `/ (root)`. Pour utiliser `solidhandinternational.org`, configurez ensuite le domaine personnalisé dans GitHub Pages et les enregistrements DNS correspondants chez le fournisseur du domaine.
